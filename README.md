# 🎓 Student To-Do List

A simple and interactive To-Do List website designed for students.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Tasks are saved automatically
- Responsive design
- Clean and simple interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## 📂 Project Structure

student-todo-list/
│
├── index.html
├── style.css
├── script.js
└── README.md

## 🚀 How to Use

1. Open the website.
2. Enter your study task.
3. Click "Add Task".
4. Check the box when the task is completed.
5. Delete tasks when they are no longer needed.
